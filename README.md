# Project Management Dashboard Sample

A sample project management dashboard built with HTML, CSS, and JavaScript. This repository demonstrates a functional dashboard interface for managing projects, tasks, and team collaboration.

## Features

- **Project Overview** - View and manage all your projects at a glance
- **Task Management** - Create, track, and organize tasks within projects
- **Team Collaboration** - Monitor team member activities and assignments
- **Dashboard Analytics** - Visual representations of project metrics and progress
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Interactive UI** - Dynamic interface with smooth interactions

## Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling and responsive layout
- **JavaScript** - Dynamic functionality and interactivity
